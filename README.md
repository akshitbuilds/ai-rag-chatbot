# 🤖 AI RAG Chatbot with Web Search

## 📌 Overview
This project is an AI chatbot that combines:
- RAG (Retrieval-Augmented Generation)
- Web Search (SerpAPI)

It answers questions using:
1. Website data (Debales AI)
2. Real-time Google search

---

## 🚀 Features
- Smart routing (RAG vs Search)
- Vector database using HuggingFace embeddings
- LLM responses using Groq (LLaMA 3.1)
- Clean and accurate answers

---

## 🛠️ Tech Stack
- Python
- LangChain
- Groq API
- HuggingFace
- SerpAPI
